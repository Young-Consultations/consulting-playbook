# Consulting Content

This directory provides a durable lifecycle for AI-SDLC consulting posts. The
[canonical content inventory](ideas/ideas-backlog.md) is the single source for
the status and relationships of every post, derivative, and idea:

```text
idea → developing → draft → ready-to-publish → published
```

| Location | Purpose |
| --- | --- |
| [`ideas/ideas-backlog.md`](ideas/ideas-backlog.md) | Canonical inventory for all content statuses, evidence, assets, derivatives, and series |
| [`drafts/`](drafts/README.md) | Content files for work-in-progress posts; status remains canonical in the inventory |
| [`published/`](published/README.md) | Copies or canonical Markdown versions of genuinely published posts; status and public URL remain canonical in the inventory |
| [`templates/`](templates/) | Lightweight idea and post templates |

Content may draw from the [Engineering Journal](../engineering-journal/README.md), [case studies](../case-studies/README.md), [defect metrics](../defects/metrics-definition.md), and appropriately handled project experience. Verify evidence, protect sensitive information, and preserve links to source records where practical.

Posts communicate consulting insight; they are not authoritative requirements, architecture, approval, or implementation records. Publication requires human review and the applicable publication decision.

Supporting research and notes should normally remain with the relevant idea or draft in a clearly named sibling file or subdirectory. Link source material and distinguish research claims from approved project truth.
