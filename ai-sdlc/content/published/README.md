# Published Posts

Store a copy or canonical Markdown version of each genuinely published consulting post here. Do not use this directory for drafts or fabricate publication records.

Where practical, include title, publication date, platform, public URL, related case study or journal entries, and `status: published`. Published content is not authoritative product documentation.

The [canonical content inventory](../ideas/ideas-backlog.md) is authoritative for
publication status and URLs. Do not add a published file until its public URL is
verified and the inventory is updated.
