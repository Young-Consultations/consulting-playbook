# Pilot proposal and statement of work

Generic drafting material; complete in an authorized engagement workspace and
obtain appropriate legal/procurement review before client use.
The [canonical pilot](../01-service-offer/active-software-delivery-assessment-pilot.md)
controls the experiment boundaries. The fee and payment terms are unvalidated
commercial hypotheses until separately agreed with the buyer.

| Section | Proposed pilot terms / fields to complete |
| --- | --- |
| Parties and authority | Identify buyer, consultant, sponsor, and decision owner. |
| Decision and objective | Exactly one delayed feature, integration handoff, or release decision; desired action within 30 days. |
| Inputs | Agree no more than five suitable sanitized artifacts, permissions, and input receipt date. No system access. |
| Schedule | Five-business-day turnaround after agreed inputs and confirmed scope; record start/delivery dates and agree reset for missing inputs. |
| Meetings | 45-minute kickoff and 30-minute readout as specified by consulting issue #86, included in delivery effort. |
| Deliverables | Concise delivery map, no more than three evidence-backed findings, prioritized two-week actions with owners and verification steps. |
| Fee hypothesis | $750 fixed fee. |
| Payment hypothesis | $375 booking / $375 delivery; record invoice/payment dates when agreed. |
| Revision | One clarification revision within scope; record request deadline and return date. New evidence/investigation excluded. |
| Effort | Five-hour delivery-effort cap including preparation, review, analysis, report, meetings, and revision. Confirm fit before booking. |
| Exclusions | Implementation, production changes, system access, exhaustive code/security audit, legal advice, certification, personnel evaluation, multi-team scoring, broad AI transformation, 30/60/90 roadmap, implementation backlog, ongoing management, extra problems/artifacts/findings/interviews/revisions. |
| Responsibilities | Buyer supplies authorized sanitized inputs, timely availability, and action owners; consultant provides advisory findings and discloses limitations. Buyer owns decisions and implementation. |
| Review | Check delivery map, evidence references, finding cap, action priorities, owners, verification steps, and agreed scope at readout. Record acknowledgment and clarification needs; no automatic acceptance. |
| Change control | Stop and agree reduced scope or separately authorized larger engagement when fit fails; no silent scope expansion. |
| Confidentiality / termination / signatures | Reference governing agreement, retention/deletion terms, authorized signatories, and dates. Keep private evidence outside this repository. |

AI is contextual if relevant to this decision, not a required positioning theme.
